# **App Name**: XCrafter AI

## Core Features:

- Image Analysis: Identify recyclable items from uploaded or captured images using an AI model. The tool should be able to identify multiple objects in a single image.
- Project Suggestion: Suggest creative DIY project ideas based on the identified recyclable items using an AI model. Prioritize projects that can utilize the majority of the identified items.
- Step-by-Step Guide: Display a step-by-step guide for each suggested project, with clear instructions and visual aids.
- Save Projects: Allow users to save their favorite project ideas.
- Help? Feature: If user click it in the step (every step has its own help? button) , search related videos with the step to help user.

## Style Guidelines:

- Primary color: Dark green (RGB(29, 102, 39)) for text and icons.
- Secondary color: Light beige (#F5F5DC) for containers to give a clean, natural feel.
- Accent color: Light green for highlights and call-to-action buttons.
- Background color: White.
- Clean and intuitive layout with a focus on visual clarity.
- Use simple, eco-friendly icons to represent recyclable materials and project steps.
- Subtle animations to guide users through the app and provide feedback.
